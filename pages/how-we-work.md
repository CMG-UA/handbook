# Information server

If you want to work on the server there are some basic things you need to know. It is very important that you know these things, it will make your life on the server easier but also our life as support. 

## Logging in
There are a couple of ways that you can access the server.\
There are two options: 
* MobaXterm
    [INSTALL MobaXterm](https://mobaxterm.mobatek.net/){: .btn}
* WSL (windows subsystem linux) 
    [INSTALL WSL](https://learn.microsoft.com/en-us/windows/wsl/install){: .btn}

Normally, if you follow these installation instructions, it should all go very smoothly.

{:  .note    }
If you work on a mac, you can just use the terminal and don't need to install any extras. 

## Moving files from local to the server 
A tool that you can use to do this easy is **WinSCP** [INSTALL WINSCP](https://winscp.net/eng/download.php){: .btn}
