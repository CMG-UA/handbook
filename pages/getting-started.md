## First time loggin in
The server address is: login.biomina.be (143.169.238.111)

You need your username and password (if first time logging in the tmp password) to log in to our login server with your favorite ssh client. 

In /opt/  you’ll find different pre-installed software packages as well as some shared files and reference data that are publicly available. 
* /opt/NGS/binaries
* /opt/software/ 
* /opt/NGS/References/
* /opt/shared_files/slurm_template/
